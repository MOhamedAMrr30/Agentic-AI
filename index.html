Multi-agent research assistant

GenAI / Agentic AI

Build a LangGraph multi-agent system that autonomously researches a topic: one agent searches, one summarizes, one critiques, one synthesizes — producing a structured report.

  • LangGraph
  • LangChain
  • Tavily API
  • OpenAI API
  • FastAPI
  • Streamlit

Real-world problem

Agentic AI is the frontier of GenAI engineering. Single-agent RAG is now a commodity skill — multi-agent orchestration with LangGraph is where 2025 interviews are heading.

System architecture

User inputs research topic → Planner agent decomposes into sub-questions → Search agents run parallel Tavily queries → Summarizer condenses each result → Critic agent scores source credibility → Synthesizer writes final structured report → FastAPI serves the result, Streamlit shows agent trace.

Build milestones

  • Build single-agent search + summarize loop with LangGraph StateGraph
  • Add parallel branching: 3 search agents running concurrently
  • Implement Critic agent that scores and filters low-quality sources
  • Add streaming output so the user sees the report being assembled in real time
  • Deploy FastAPI + Streamlit with a public HuggingFace Space demo

Success metric

Report quality score (human eval), end-to-end latency, source credibility, filter precision.
